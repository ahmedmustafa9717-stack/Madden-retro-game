# Pocket Football

A browser-based 11-on-11 American football prototype built with Three.js. Open `dist/index.html` in a browser or serve the `dist/` folder with a static web server. The game includes player models, a stadium, passing, scoring, and replay.

The source art and Blender scripts live in `assets/`. The playable build lives in `dist/`; a regression suite lives in `tests/`.
